    Roadmap to the platinum — seven stages, in order

    Play in this order and nothing blocks the platinum: story first, then partner crime, activities, side strands, collectibles, crime mastery, and the money cleanup last. Each stage lists the trophies it unlocks, with the stage's own advice.

    Missables — read this before Chapter 1 ends

    Only one trophy can truly be missed. Six more are flagged watch: they are not missable in the strict sense, but they fail if you do them in the wrong order or without the right setup. Everything else can be finished after the story.

    Sources — where each fact comes from

    Every guide step names its source beside it. Names, descriptions and grades come from the official PlayStation list as published before this guide was written. Where the sources disagree, or where only one source speaks, the guide says so instead of pretending to be certain.

    How sure are we?

    • Confirmed — several sources agree, and the step follows the official description.
    • Watch — doable any time, but the setup or order matters; read the warning first.
    • Disagree — the sources used here give different methods; the guide names the conflict.
    • Unconfirmed — the official description is vague and no source pins the method down yet.
    • Single-source — only one of the eight sources covers this trophy; treat it as a lead.
